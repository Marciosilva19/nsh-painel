# NSH · Painel de Gestão

Painel de gestão da No Safety Hood: produtos, variantes, stock, reservas, coleções, custos e simulação de receita e lucro (USD).

- App: https://marciosilva19.github.io/nsh-painel/
- Dados: Supabase (projeto `nsh-painel`), acesso só com sessão iniciada.
- Estrutura da base de dados: `supabase-nsh.sql`.
